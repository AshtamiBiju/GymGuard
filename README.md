# 🏋️ GymGuard

GymGuard is a gym membership management and access monitoring web application designed to streamline member administration and subscription tracking. The system provides secure authentication, membership approval workflows, access history tracking, and administrative tools for managing gym operations.

## 🚀 Features

* 🔐 Secure user authentication using JWT
* 👤 Member registration and login system
* ✅ Admin approval workflow for new member accounts
* 📊 Admin dashboard with:

  * Active members overview
  * Pending approval requests
  * Daily entry statistics
* 📅 Membership management with start and expiry date tracking
* ✏️ Editable membership expiry dates for administrators
* 📈 Member dashboard displaying:

  * Subscription status
  * Days remaining until expiry
  * Personal access history
* 🚪 Entry validation system based on:

  * Account approval status
  * Membership validity
* 📝 Logging and tracking of access attempts
* 📧 Automated email reminders for memberships nearing expiration

## 🛠️ Tech Stack

### Backend

## 🎯 Project Goal

GymGuard simplifies gym administration by providing a centralized platform for member management, subscription monitoring, access tracking, and automated notifications, helping gym staff efficiently manage memberships and member activity.
